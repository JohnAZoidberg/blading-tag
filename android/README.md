# android

Kotlin app that runs during a skate session.

**Not written yet.** Phase 5 in [../PLAN.md](../PLAN.md).

What it will do:

- Find and connect to one or two tags, then start and stop recording.
- Keep recording with the screen off (foreground service).
- Log the raw IMU stream and GPS to a file, and export it for analysis.
- Later: show push rate live and update the tag's firmware.
